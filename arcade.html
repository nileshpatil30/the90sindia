How the Arcade works

  • We only list original classic games, never clones or remakes, and we host no game files, ROMs or BIOS files.
  • A game plays on this site only if its owner explicitly allows embedding. None do yet, so today every playable game opens on the owner’s own site.
  • Each game’s page shows what we checked: software licence, embedding, commercial use and the date we last checked.
